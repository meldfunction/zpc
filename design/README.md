# Design source files

The original Claude Design export ("Worker cooperative redesign"), kept for reference and re-export.

- `Zen Privacy Collective.dc.html`: the redesign as exported. The live `index.html` is this file plus the edits listed in the top-level README ("Re-exporting from Claude Design").
- `Current Site - Home.dc.html`: a mock of the previous site's home page, used as the starting point.
- `github.md`: the export's sync notes (screen-to-file map).

To preview a `.dc.html` file, copy it to the repo root (next to `support.js` and `zpc-data.js`) and serve the folder.
